# Sales Data Cleaning & Analysis using Python

## Project Overview
This project focuses on cleaning and analyzing messy sales data using Python libraries such as NumPy, Pandas, Matplotlib, and Seaborn. The dataset contained inconsistencies including missing values, incorrect formatting, duplicate entries, inconsistent text values, and mixed data types.

The goal of this project was to transform raw, unstructured sales data into a clean and analysis-ready dataset while extracting useful business insights through visualization.

## Features
- Data cleaning and preprocessing
- Handling missing/null values
- Removing duplicates
- Fixing inconsistent text and formatting issues
- Converting incorrect data types
- Data transformation and feature engineering
- Exploratory Data Analysis (EDA)
- Data visualization using charts and graphs

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Dataset Issues Solved
The dataset contained several common real-world problems:

- Missing values
- Duplicate records
- Inconsistent category names
- Incorrect formatting
- Mixed or invalid data types
- Unclean text entries
- Improper numerical values

After cleaning, the dataset became structured, reliable, and suitable for analysis.

## Project Workflow
1. Importing and understanding the dataset  
2. Detecting data quality issues  
3. Cleaning and preprocessing the data  
4. Performing exploratory data analysis (EDA)  
5. Visualizing sales trends and patterns  
6. Generating insights from cleaned data  

## Visualizations
The project includes multiple visualizations to better understand sales patterns, trends, and distributions using Matplotlib and Seaborn.

Examples include:
- Sales distribution
- Profit analysis
- Category-wise comparison
- Trend analysis
- Correlation analysis
